# Cryptography Basics

This folder contains the slides used for the "Cryptography Basics" session on October 17, 2025.

- Slides (Spanish) PDF (frame-by-frame version of the animated slides): [criptografia_conceptos_fundamentales.pdf](./criptografia_conceptos_fundamentales.pdf)
- Speaker: [Sebastián Giraudo](https://github.com/sebagiraudo)

## Overview

A compact introduction to some cryptography concepts relevant to Ethereum development:

- Why we need proof systems.
- Interactive proofs.
- From interactive to non-interactive: Fiat–Shamir.
- A simple interactive proof example: Sudoku.
- How zero-knowledge proofs are used: Tornado Cash.

(The slide deck is in Spanish)

## Suggested reading

- 0xPARC's book: [Introduction to Programmable Cryptography](https://github.com/0xPARC/0xparc-intro-book)
